## Nanobot-Website (nanobot.gg)

This is a [Next.js](https://nextjs.org/) project bootstrapped with [`create-next-app`](https://github.com/vercel/next.js/tree/canary/packages/create-next-app). The headers below are part of the default README of a Next.js application.

This project uses [`next/font`](https://nextjs.org/docs/basic-features/font-optimization) to automatically optimize and load Inter, a custom Google Font.

This code was written by uxuz, completed by tanosshi, and maintained by piscatus.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
```

If utilizing docker, run the docker-compose command:
docker compose up --build -d

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
